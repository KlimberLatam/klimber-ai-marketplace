# Security policy

## Reporting a vulnerability

**Do not open a public issue.** Email **infosecurity@klimber.com** with:

- the affected plugin or file,
- steps to reproduce,
- the impact you see.

We reply within 3 business days.

## Scope

This repository contains manifests, skills and MCP configuration. It must not contain secrets.
If you find a credential in the history, report it through the same channel so it can be rotated.

## Marketplace guarantees

- Plugin tools are read-only unless stated otherwise.
- Authentication is handled by the MCP server; no plugin stores credentials on disk.
